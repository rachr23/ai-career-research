# AI Career Research

A VitePress research portfolio exploring emerging AI job titles, employer job descriptions, skills, and pathways for business and data analytics students.

## Live website

**GitHub Pages:** `https://YOUR-GITHUB-USERNAME.github.io/ai-career-research/`

Replace `YOUR-GITHUB-USERNAME` with your GitHub username after creating the repository. The link works once GitHub Pages deployment succeeds.

## Research sections

- Emerging AI careers
- Job description research
- Skills and qualifications
- Career comparison
- My career direction
- Sources and AI usage

## Run locally

```bash
npm install
npm run docs:dev
```

## Publish

1. Create a public GitHub repository named `ai-career-research`.
2. Push these files to the `main` branch.
3. In GitHub **Settings → Pages → Build and deployment**, choose **GitHub Actions**.
4. Wait for the **Deploy VitePress to GitHub Pages** workflow to succeed.
5. Update the website link above with your username.

This site is a research work in progress. Job posting claims should be verified against original sources.
